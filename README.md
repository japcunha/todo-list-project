# 📝 To-Do List Fullstack

Um aplicativo Fullstack de lista de tarefas, onde usuários podem cadastrar, visualizar, atualizar e excluir tarefas. Inclui autenticação com JWT e integração com banco de dados.

## 🚀 Tecnologias Utilizadas

### Frontend:
- [HTML] 
- [CSS] 
- [JAVASCRIPT] 

### Backend:
- Node.js (https://nodejs.org/)
- [Express.js](https://expressjs.com/)

### Database
- [MySQL]
